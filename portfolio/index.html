THE CHALLENGE

Choosing what comes next
should feel less uncertain.

01

Too many choices

Connecting interests, academic strengths, and career ambitions to the right programme can be difficult.

02

Scattered resources

Useful learning material is easier to act on when it relates to what a student wants to study.

03

Opaque suggestions

Students deserve to see why an option appears, with matching factors they can review for themselves.

THE APPROACH

Guidance with the
reasoning included.

The system brings student profile data and an editable university catalogue together to produce understandable recommendations.

↗

01 / PERSONALISE

Start with the student

Build a profile from academic background, subjects, interests, career direction, learning style, and study preferences.

⌕

02 / COMPARE

Match across useful signals

Compare profile details with programme and resource catalogue entries using structured features and text similarity.

☷

03 / EXPLAIN

Make the fit visible

Show ranked options with matching factors, skill gaps, and suggested next steps to guide further exploration.

UNDER THE HOOD

Recommendations,
not black boxes.

Content-based matching combines feature overlap with TF-IDF and cosine similarity. The result is a ranked list students can inspect and discuss.
