STUDENT JOURNEY

A profile that informs recommendations

Students can register, sign in, create or edit a profile, and view their dashboard. The profile supports academic and personal study context relevant to programme and resource matching.

SCOPE & LIMITS

A useful prototype,
with clear boundaries.

+

What it demonstrates

A complete student profile flow, catalogue-backed recommendation features, transparent matching signals, and maintainable content management.

i

What it does not claim

The system has no real labelled student behaviour dataset. It is an explainable academic prototype, and catalogue quality affects recommendation usefulness. It should not be treated as an admissions decision tool.

GETTING STARTED

Run it locally.

From the project root, create an environment, install the listed requirements, apply migrations, load the catalogue, and start Django's development server.

Read how the matching works →
TERMINAL
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_catalogue
python manage.py runserver

Then open the local address shown by Django in your browser.
