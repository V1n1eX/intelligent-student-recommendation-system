About the project

The Intelligent Student Recommendation System is a full-stack Django application designed to help students identify suitable academic programmes and learning resources. It combines structured profile data and content-based recommendation methods to produce explainable matches.

Objectives: support academic decision-making, encourage self-directed learning, and provide a transparent recommendation workflow grounded in catalogue data.

Technology: Django, SQLite, scikit-learn, pandas, numpy, Bootstrap 5, and GitHub Pages for the portfolio website.
